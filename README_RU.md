## Возможности

- **Форма заявки с живой валидацией.** Ошибка появляется, когда человек уходит с поля, и обновляется прямо во время ввода. Есть маска телефона, проверка ФИО на кириллицу и шкала заполненности.
- **Умная форма.** Если ввести ИНН из 12 цифр (ИП), юридический адрес становится необязательным.
- **Отправка заявок.** Заявки уходят в функцию Яндекс Облака, а она записывает их в Google Таблицу.
- **Контент в JSON.** Все тексты, навигация, партнёры и даты лежат в `src/data/*.json`. Контент можно править, не трогая компоненты.
- **Адаптивная вёрстка.** Заголовки блоков стоят по центру на мобилке и планшете и слева на десктопе. Логотипы партнёров масштабируются вместе с экраном и сохраняют пропорции между собой.
- **Анимации.** Framer Motion отвечает за полноэкранное мобильное меню и появление блоков при скролле. Анимации намеренно лёгкие.
- **Юридические страницы.** `privacy.html` и `terms.html` собираются отдельными страницами вместе с лендингом.

## Стек

React · TypeScript · Vite · Tailwind CSS · Framer Motion

## Структура проекта

```
public/
  assets/            картинки, логотипы, иконки
  .htaccess          настройки сервера для хостинга reg.ru
src/
  components/        общие компоненты (SectionHeading, Reveal, Logo…)
  sections/          блоки страницы (Header, ApplicationForm, Speakers…)
  pages/             юридические страницы
  data/              весь контент сайта в JSON
  lib/               вспомогательные функции
  main.tsx           точка входа лендинга
  legal-main.tsx     точка входа юридических страниц
index.html
privacy.html
terms.html
```

## Хостинг

Статическая сборка на виртуальном хостинге reg.ru, деплой по SSH.
