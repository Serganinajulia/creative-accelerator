# Креативная среда. Акселератор — лендинг

React + TypeScript, статичный лендинг без CMS. Весь редактируемый контент — в `src/data/*.json`.

## Запуск

```bash
npm install
cp .env.example .env   # и подставь реальный VITE_FORM_ENDPOINT, когда будет готова функция на Яндекс.Облаке
npm run dev
```

Откроется http://localhost:5173

## Структура

```
src/
  components/   переиспользуемые элементы (Reveal — scroll-reveal, useSmoothScroll — Lenis)
  sections/     блоки лендинга (Header, Hero, ForWhom, WhatYouGet, Program, Speakers, ...)
  data/         texts.json, dates.json, program.json, speakers.json, partners.json
  assets/       картинки, иконки, фирменная 3D-графика (положить сюда, когда пришлёт дизайнер)
```

## Что уже сделано

- Каркас всех блоков лендинга по порядку из ТЗ
- Плавный скролл по всей странице (Lenis)
- Scroll-reveal анимация появления блоков (Framer Motion)
- Первый экран: заглушка 3D-графики с лёгким вращением + параллакс на скролл
- «Для кого»: две встречные бегущие строки (разная скорость, разный вес шрифта)
- «Что получите»: bento-карточки с градиентным spotlight за курсором
- «Программа»: градиентные цифры {01}–{06}
- «Эксперты»: горизонтальные карточки в слайдере (фото слева, текст справа, иконка в углу)
- Форма заявки: поля ровно по Приложению №1 к Договору, валидация телефона/почты по нужным форматам, отправка на `VITE_FORM_ENDPOINT`
